# DEV LOG: Bug #8.5 — updateTemplate Defensive Unwrap Complete (2026-08-31)

## Bug Summary

**Severity**: SEV-2 (P0 data-loss — incomplete P0 fix)

**Bug**: Bug #8 (2026-08-31) attempted to fix `templates.settings` JSONB corruption by adding a defensive unwrap in `updateTemplate`. **The fix was incomplete** — it handled the case where `settings` itself is an array of partial merges, but did NOT handle the case where the array's last element is itself a jsonb **string** (legacy corruption stored `JSON.stringify(obj)` inside the array).

**Root cause**: Bug #8's `WHEN 'array' THEN settings -> -1` returns whatever type the last element is. When the element is a jsonb string (not object), the subsequent `string_settings || jsonb_object_new` falls into PostgreSQL JSONB concat's "All other cases" rule — converting the result to a text array, re-corrupting on every PUT.

**Migration 010 already had the right pattern** (nested CASE WHEN for string-element unwrap), but `updateTemplate` failed to mirror it.

## Why This Bug Existed (Lesson Learned)

- Bug #8's 3 regression tests only asserted SQL pattern matching (`WHEN 'array'`, `settings -> -1`), not the actual runtime behavior of the unwrap.
- A passing test that says "the SQL contains the right keywords" does NOT prove the SQL returns the right value.
- **TDD lesson**: write tests that exercise the **behavior** (what does the SQL return for each input type), not tests that exercise the **implementation** (does the SQL contain these strings).

## What Was Done

### Phase 1 — Source Fix: `apps/backend/src/modules/cards/db/templates.ts`

Added nested CASE WHEN inside the `WHEN 'array'` branch:

```sql
WHEN 'array'  THEN (
  CASE jsonb_typeof(settings -> -1)
    WHEN 'string' THEN ((settings -> -1) #>> '{}')::jsonb
    WHEN 'object' THEN (settings -> -1)
    ELSE '{}'::jsonb
  END
)
```

Updated docstring to clarify nested unwrap semantics.

Added 2 new regression tests in `apps/backend/src/modules/cards/tests/updateTemplate.merge.test.ts`:
- `parses jsonb string element before merge when array tail is string` — verifies nested CASE WHEN structure
- `passes through jsonb object element when array tail is object` — verifies dual WHEN 'object' branches
