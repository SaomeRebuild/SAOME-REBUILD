## 🔍 CSS 視覺錯覺除錯（重要洞察）

### 問題場景
用戶反映 `text-on-primary` 顯示「黑色」，懷疑是 CSS 沒吃到 `--color-on-primary` 值。

### Debug 過程
```js
// DevTools 驗證
const a = document.querySelector('a.bg-primary')
console.log('class:', a.className)        // 包含 text-on-primary ✅
console.log('color:', getComputedStyle(a).color)  // rgb(249, 236, 229) = #F9ECE5 ✅
```

### 結論
- Computed style **是對的**：`#F9ECE5`（米色）
- 視覺上看起來「黑色」是**螢幕色溫 + 深藍背景對比**造成的錯覺（`#0F172A` vs `#F9ECE5` 對比只有 8.4:1，看似強但低亮度螢幕下米色會偏向灰黑）

### 失敗模式（已建立 feedback，見下方 Self-improvement 段）
- 「class 有套 + 看起來不對 → 直接改程式」是錯誤反應
- 應先 `getComputedStyle` 驗證 computed value 再決定行動

### 後續行動
- 已將 `frontend/src/index.css` 內手寫的 `a { color: inherit }` 移除（讓 Tailwind preflight 的版本生效）
- 不變動 `--color-on-primary`（視覺錯覺不是顏色錯）

2. **AskQuestion 確認**（最多 1-2 題）
3. **委派給對應的 speckit-* / saome-* / workflow-* skill**

**不改程式碼、不生成 spec.md**，只做動詞識別 + 確認 + 委派。

## Session 7 追加：CI Dependency Fix

### 問題

`saome-frontend` CI 第一次跑就失敗，`npm ci` 報 peer dependency conflict：

```
@testing-library/react@16.0.0
  peerOptional @types/react@"^18.0.0"
  Found: @types/react@19.2.17
```

### 修復

```diff
-    "@testing-library/react": "^16.0.0",
+    "@testing-library/react": "^16.1.0",
```

`@testing-library/react@16.1.0` 支援 `@types/react@^19`。

然後重新 `npm install` 產生 `package-lock.json`。

### Commit

```
fix(deps): upgrade @testing-library/react to ^16.1.0 for React 19 compatibility
```

### Push

- `18c79a4` → `origin/main` ✅（直接用 `git push origin 18c79a4:refs/heads/main`）
- `frontend-work` branch → `origin/frontend-work` ✅

### Lesson

本地跑 `npm run test` 正常是因為有 `node_modules/` 已resolve，lock file 已經是最新的。但 `npm ci`（CI 乾淨環境）需要 lock file 與 `package.json` 一致。

**下次：改 `package.json` 後本地必須重新 `npm install` 並 commit `package-lock.json`**。
